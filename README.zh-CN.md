# Monash Exchange Tracker — 公开演示版

[English](README.md) · **简体中文**

[公开演示](https://waldo0926.github.io/monash-abroad-tracker-demo/) · [虚构当前数据](./data/current.json) · [虚构上一轮基准](./data/comparison.json)

这是 **Monash Abroad 交换项目变化追踪器** 的公开作品集演示版。

完整项目会抓取 Monash 项目搜索页的数据，标准化项目字段，对不同运行结果和不同申请轮次进行字段级比较，记录变化，并生成可搜索、筛选和排序的查看页面。由于完整项目仍与在读课程项目有关，其生产仓库目前保持私有。

这个公开仓库用于展示查看器和“上一轮 vs 当前轮”的对比流程，不公开生产环境中的真实抓取数据，也不公开完整抓取器实现。

> **虚构数据说明：** 本仓库中的大学、国家/地区、URL、成绩要求、竞争状态、上一轮数值和名额数字均为虚构内容，不包含任何真实的 Monash 交换项目记录。

## 这个 Demo 展示什么

- 英文 / 简体中文界面切换
- 按大学或国家/地区搜索
- 使用接近正式版的左侧多维 checkbox 筛选器：地区、学期、时长、可申请校区、可申请学院、申请状态和竞争状态
- 同一筛选维度内采用 OR，不同筛选维度之间采用 AND
- **动态联动的筛选数量**：其他条件改变后，各选项右侧的数量会同步更新
- 根据当前筛选结果动态更新的 Total / Green / Yellow / Red / Closed 顶部统计卡
- 点击表头进行交互式排序
- 展示最低要求、上一轮分数线和预计名额
- **自动读取虚构上一轮基准进行对比**，生成竞争 ↑/↓、名额 ↑/↓、分数线 ↑/↓、转开放 / 转关闭、新增等变化标签
- 展示搜索页与详情页字段不一致的警告
- 当前记录使用与私有正式项目一致的 canonical JSON 字段结构
- 响应式布局：小屏幕下会把左右两栏自然折叠为单栏

公开页面会明确标注为 **static portfolio dataset（静态作品集数据）**，避免访问者误以为这是实时生产数据页面。

## 对比功能如何工作

`data/current.json` 表示完全虚构的当前轮数据，`data/comparison.json` 则是一份独立的虚构上一轮基准。页面加载后会真正比较这两份数据，再动态生成“变化”标签，而不是把“竞争↓”“名额↑”等结果直接写死在 HTML 里。

变化方向的语义与正式版保持一致：同口径分数线上升、竞争变激烈属于不利变化；名额增加、同口径分数线下降、竞争缓和或重新开放属于有利变化。

## 公开 Demo 与正式项目的区别

| 组成部分 | 正式项目 | 本公开 Demo |
| --- | --- | --- |
| Scraper / crawler | 位于私有仓库 | 不公开 |
| 当前数据结构 | 正式 tracker schema | 演示字段使用同样结构 |
| 数据 | 实际抓取记录 | 18 条完全虚构记录 |
| 上一轮对比 | 真实冻结基准 | 独立的虚构基准 |
| Viewer | 正式查看器 | 使用相同交互与对比思路的作品集安全版 |
| 自动抓取 | 定时执行 | 不包含 |
| 历史变化追踪 | 完整的 append-only history 与 snapshots | 只展示静态虚构的轮次对比 |

## 仓库结构

```text
.
├── index.html              # 搜索、多维筛选、变化标签、双语界面
└── data/
    ├── current.json        # 使用 tracker schema 的虚构当前数据
    └── comparison.json     # 用于变化检测的虚构上一轮基准
```

## 本地运行

页面通过 `fetch()` 加载 JSON，因此不要直接双击打开 `index.html`，而应启动一个简单的本地 HTTP server：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 为什么正式仓库保持私有

正式 tracker 中包含实际的数据收集实现以及真实抓取到的交换项目数据。当前保持私有，可以避免在课程项目仍处于活跃阶段时公开评估相关源代码和生产数据，同时又能通过本仓库向招聘方展示界面、数据模型和轮次对比逻辑。
